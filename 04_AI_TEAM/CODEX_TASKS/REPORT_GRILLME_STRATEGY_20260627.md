## 0. 总裁决

我接受当前战略姿态的主方向：**核心研究仍应留在加密，核心资本不碰，量化主动猎暂停，先让投研/前向记录承担发现功能**。理由不是“其他市场没有机会”，而是当前项目的目标函数、账户规模、可做空性、24x7、结构数据和工程复用度仍最匹配加密。

但我不接受当前姿态的三个隐含强断言：

1. **“只做加密”不应等于关闭外部猎场雷达**。容量 edge 不可迁移，不代表事件结构化、信息延迟、执行纪律、前向评分方法不可迁移。
2. **“付费数据推迟到投研前向战绩证明之后”太粗**。应该区分“生产级月订阅”和“数据尽调/样本/短试用”。完全等前向战绩，容易陷入免费残缺数据证明不了、付费数据又永远不买的循环。
3. **三账户分层还缺升级/降级协议**。Research、Paper-forward、裁量沙盒如果没有明确 promotion gate、污染隔离和失败注销规则，会变成标签，而不是控制系统。

因此我的建议是：**保留当前姿态，但加五个小修正**：

1. 建立前向投研 ledger：每条判断必须有时间戳、可见信息、方向、期限、触发条件、失效条件、仓位假设、基准对照、结果评分。
2. 设置“数据尽调预算/权限”而非“生产数据订阅”：允许一次性样本、schema、trial、有限月份购买；禁止自动续费和核心资本交易。
3. 给三账户写 promotion/demotion gate：什么条件从 paper-forward 进 research，什么条件注销，什么情况永不进核心。
4. 给被动强平数据设置数据质量 SLO：覆盖率、断流、字段变更、价格/OI/funding 对齐、incident log、每周审计。
5. 每 4 周做一次极小外部 benchmark scan：只看美股/黄金/A 股是否出现明显更便宜的可审计事件数据机会，不开主线、不占研究 WIP。

## 1. Grill-me 决策树压测

### Q1：为什么此路，而不是放开美股/A 股/黄金白银？

**推荐答案**：当前核心猎场继续只做加密是合理的。加密合约在多空表达、杠杆、24x7、结构数据、账户门槛和小资金容量上仍最适配项目目标。美股事件、A 股散户行为、黄金宏观事件都有机会，但它们要么数据/竞争成本更高，要么做空与制度约束更重，要么 universe 太窄，不适合作为当前主线。

**压测分歧**：当前姿态的“容量 edge 不可迁移”表述过硬。不可迁移的是某些小盘成交容量、交易所微结构、滑点承载力；可迁移的是事件定义、前向评分、信息延迟、数据审计、风控 promotion gate。若完全关闭外部雷达，项目可能被加密数据商付费墙困住，却错过其他市场更公开、更可审计的事件表。

**最小修正**：不是放开多市场研究，而是加一个低成本 benchmark：每 4 周只花固定半天，检查外部市场是否出现“可审计、低成本、事件表完整、可做前向评分”的候选。没有则继续 crypto-only。

### Q2：为什么投研线领跑、量化主动猎暂停？

**推荐答案**：合理。免费价格族和低维动量已经多次失败；强平、解锁、OI/funding 等硬机制又连续撞数据门。此时继续让 Codex 做大规模主动猎，容易把同一类数据缺口重复包装成新任务。投研线可以更快发现“哪类事件值得买数据/建数据”，paper-forward 可以给真实时间顺序约束。

**压测分歧**：投研线若没有结构化 ledger，会退化成 narrative alpha。关键不是“前向看准几次”，而是有无完整分母：看了多少事件、明确拒绝了多少、无交易判断是否计入、错过是否计入、同类事件中命中是否单调。没有 ledger，前向战绩会天然偏向展示成功案例。

**最小修正**：投研线从第一天起使用 prediction ledger。每条预测至少写：`timestamp_utc`、`visible_info`、`event_type`、`symbol`、`direction`、`horizon`、`trigger`、`invalidation`、`benchmark`、`notional/slippage_assumption`、`outcome`、`score`。不允许用聊天记忆或精选截图当战绩。

### Q3：为什么付费数据要推迟到投研前向战绩证明之后？

**推荐答案**：作为生产订阅原则，合理。项目不应因为一个机制“看起来硬”就直接每月付费，更不能用付费数据绕过 v1.3 验收。先用免费边界、前向判断和小样本证明方向感，是保护现金和纪律。

**压测分歧**：把所有付费数据都推迟到前向战绩之后，会形成循环依赖。解锁、强平这类机制的核心真值本来就在付费墙后；如果没有事件表，投研前向只能靠零散网页、文章、手工观察，证明的是“研究员是否会挑样本”，不是机制是否可系统化。Claude 已指出这是数月慢路；grill-me 进一步指出：**它还是一个被免费残缺数据污染的证明门**。

**最小修正**：拆成两类预算。

1. **Data diligence**：一次性样本、schema、trial、有限月份历史，目标是判断字段、覆盖、时间戳、缺失、许可证、能否重放；金额封顶，不自动续费，不用于核心交易。
2. **Production subscription**：只有通过前向 ledger + 样本审计 + B1/B2 门后才允许。

这样不破坏“先证明再花钱”的纪律，但避免把必要的数据尽调也锁死。

### Q4：为什么三账户分层，核心资本不碰？

**推荐答案**：完全正确。Research/Paper-forward/裁量沙盒分层是当前最重要的资本保护。项目还没形成可复现、过成本、过压力滑点、过分年正期望的策略，不应让核心资本承担学习成本。

**压测分歧**：三账户只有名字不够。真正风险在“账户之间的知识污染”：裁量沙盒看到的形态被拿去解释 paper-forward，paper-forward 的少数命中被当成 research evidence，research 的描述统计被包装成核心资本理由。必须有明确升级门，否则分层只是心理安慰。

**最小修正**：写一个 promotion/demotion 表：

| 来源 | 可升级到 | 必要条件 | 永久禁止 |
|---|---|---|---|
| 裁量沙盒 | Paper-forward 假设队列 | 连续日志、明确规则、冻结后未来验证 | 用胜率/截图直接进核心 |
| Paper-forward | Research B0/B1 | ledger 完整、样本分母可审、非同一 regime、失败样本纳入 | 只凭几次命中买生产数据 |
| Research | 核心候选 | v1.3 四件套 + 成本/滑点压力 + 分年/分档 | 未过量化验证直接下核心资本 |

### Q5：为什么强平数据后台被动攒？

**推荐答案**：合理。强平机制没有死，死的是当前免费历史全量不可得和 Binance 抽样流不能代表全量。被动攒 Bybit/OKX/Binance 等实时流是低成本期权，未来可能补足事件研究。

**压测分歧**：被动攒数不是“免费等待”。它需要数据产品纪律，否则几个月后可能得到一堆不可审计日志：断流没标、字段变更没标、交易所覆盖不一致、price/OI/funding 无法 join、symbol 上下架没版本。此前项目已经出现过采集器状态误判和本地同步断点；这说明被动攒数的第一失效点不是资金，而是运维可审计性。

**最小修正**：给强平后台数据设置每周健康检查：

1. 每交易所/每 symbol 最近消息时间。
2. 每日行数、notional、缺失段、异常零值。
3. 与 4H price、OI、funding 的可 join 比例。
4. schema hash 和字段变更记录。
5. 采集器 incident log。
6. 月末随机抽样重放，确认事件时间戳与价格时间戳可对齐。

## 2. 被否替代方案

### 替代 A：立即放开美股/A 股/黄金白银

**否决理由**：当前 WIP 会失控；多市场会引入账户、数据、制度、费用、交易时段和研究协议差异。A 股尤其不满足当前多空对称核心目标；黄金单资产太窄；美股宽基价格因子竞争过烈。

**保留部分**：只保留低成本外部 benchmark，不开正式主线。

### 替代 B：立即购买强平/解锁全量数据

**否决理由**：容易把“数据可得”误当“edge 存在”，也容易让供应商月费变成研究惯性。未过 B1/B2 前，不应长期订阅生产数据。

**保留部分**：允许 data diligence，不允许 production subscription。

### 替代 C：恢复量化主动猎，继续从免费价格族找

**否决理由**：普通价格形态、低维 momentum、简单 RV 已多次失败；继续扫会制造大量看似不同、机制同源的负样本，机会成本高。

**保留部分**：量化不主动猎，但应服务投研 ledger：做事件定义、基准收益、成本压力和可审计评分。

### 替代 D：核心资本小仓实盘试错

**否决理由**：当前没有任何策略满足 v1.3 进入核心资本的证据。小仓也会破坏组织纪律，因为一旦赚钱，容易把运气升级成制度。

**保留部分**：裁量沙盒或 paper-forward 可以训练执行，但必须固定亏损预算/零资本，并与核心隔离。

## 3. 最先崩在哪

我判断最先崩的不是“加密没有 alpha”，而是以下七个环节：

1. **投研前向战绩不可审计**：没有完整 ledger，成功案例被记住，失败和 no-trade 被遗忘。
2. **数据门循环依赖**：没有付费事件表无法证明机制，没证明机制又不能买数据。
3. **paper-forward 执行失真**：小盘/事件窗的可成交深度、滑点、borrow/funding、交易所限制没有进入前向记录。
4. **三账户边界被口头绕过**：沙盒发现被当成验证，paper 命中被当成研究结论。
5. **被动数据不可用**：采集持续了，但缺断流记录、schema 版本、join 质量和覆盖率审计。
6. **等待期无 time-stop**：投研前向可能“再等等”数月，但没有明确何时判定本路线 blocked。
7. **crypto-only 变成身份承诺**：明明是当前资源下的最优约束，却被理解为长期世界观，导致外部更便宜证据被忽略。

## 4. 依赖什么成立

当前姿态成立，必须依赖这些条件：

1. 加密仍存在可观察的 payer/forced/event flow，而不是所有硬机制都被数据商独占到不可验证。
2. Paper-forward 能形成完整、不可选择性呈现的记录。
3. 前向观察期足够覆盖多个事件和至少两个市场 regime。
4. 投研判断能转成明确可量化的事件定义，而不是停留在叙事。
5. 数据尽调可以在不破坏预算纪律的情况下取得最小真值样本。
6. 三账户之间有硬隔离和升级门。
7. 被动强平采集长期保持可审计、可 join、可复跑。

任何一条不成立，当前姿态都需要降级为“防守观察”，不能继续被描述成有效战略推进。

## 5. 什么会变，什么不可逆

### 会变

1. 数据供应商定价和免费边界会变。Tokenomist/DefiLlama/交易所 API 的免费端点随时可能变化。
2. 加密市场结构会变。小盘容量、合约上线、CEX 深度、监管限制、交易所 API 质量都会改变。
3. 事件拥挤度会变。解锁、上币、funding 极端一旦被市场广泛交易，edge 会快速衰减。
4. 项目瓶颈会变。现在是数据门，未来可能是执行门、组合门或风控门。

### 较难逆转

1. 若核心资本提前下注并亏损，纪律损害难逆转。
2. 若花数月做不可审计前向记录，时间成本不可逆。
3. 若被动数据攒了几个月后发现不可 join，机会窗口不可逆。
4. 若组织叙事变成“只做加密是信仰”，未来纠偏成本会变高。
5. 若付费数据订阅形成惯性，后续很难诚实 KILL。

## 6. 谁受影响

1. **Founder/核心资本**：受益于核心封存，但也承担等待和机会成本。
2. **Claude 主理人**：需要从“方向裁决”扩展到“前向 ledger 和 promotion gate 裁决”，否则投研线证据质量不够。
3. **Codex 实现线**：短期少做主动猎，多做数据审计、ledger、评分、可复跑工具和被动采集健康检查。
4. **Research/Paper-forward/裁量沙盒**：需要明确证据等级，不能互相借信用。
5. **未来自动化/调度器**：若前向记录格式不固定，后续无法自动评分，也无法喂给量化验证。

## 7. 最小可逆版本

最小可逆版本不是大改战略，而是加一个 14 天试运行包：

1. **14 天 crypto-only 前向 ledger**：所有投研判断进入同一 CSV/MD 表；no-trade 也记录；每天 UTC 收盘后更新结果字段。
2. **一次 data diligence 清单**：列出 unlock/liq 两类数据源的 schema、样本、trial、价格、许可证、覆盖，最多只申请/购买一个最小样本。
3. **三账户 gate 一页纸**：写清每个账户的目的、禁止项、升级门、注销门。
4. **强平采集周检脚本/报告**：只做覆盖和 join 质量，不做收益判断。
5. **外部 benchmark 半日扫描**：只输出“是否存在比 crypto 当前路线更便宜、更完整的事件真值表”，不扩 WIP。

14 天后裁决：

| 结果 | 动作 |
|---|---|
| ledger 完整且出现可量化重复事件 | 进入 B0/B1 任务书 |
| ledger 不完整 | 投研线不得声明前向战绩 |
| data diligence 显示付费样本质量差 | 不买生产订阅 |
| data diligence 显示样本质量好且前向 ledger 支持 | 允许一次有限月份数据购买 |
| 强平采集 join 质量差 | 修数据，不做策略 |
| 外部 benchmark 有明显低成本事件表 | Claude 单独裁决是否开观察支线 |

## 9. grill-me 相对 Claude 原生红队的增量

Claude 原生红队已指出两点：

1. 解锁投研样本可能单一机制，且“大额解锁 -> 跌”接近同义反复，必须考非显然判断和跨机制。
2. 解锁投研线没有直接量化升核心路径，因为会撞同一付费墙；升核心主要靠前向积累自建数据集，是数月慢路。

本次 grill-me 逼出的新增点如下：

### 新增 1：数据门不只是“慢”，还是“证明污染”

Claude 已说前向自建是慢路；grill-me 进一步指出，若免费数据缺的是事件真值，前向战绩可能证明错对象。它证明的是研究员在残缺信息环境下挑样本/解释事件的能力，不一定证明机制在全量事件表上有效。解决方式是 data diligence 与 production subscription 分离。

### 新增 2：缺少前向投研分母和评分协议

当前姿态说 paper-forward，但没有定义“战绩”的分母。没有 no-trade、拒绝样本、失败样本、基准对照和统一评分，paper-forward 会天然选择性呈现。这个盲点不同于“样本机制单一”；它是证据记录制度问题。

### 新增 3：三账户分层缺 promotion/demotion gate

Claude 支持三账户分层，但 grill-me 问“谁受影响/什么不可逆”后暴露出：账户名不能自动防止证据污染。必须写明裁量沙盒、paper-forward、research、核心之间的升级和禁止路径。

### 新增 4：被动强平攒数存在运维失效模式

当前姿态把强平数据放后台被动攒。grill-me 逼出的问题是：被动攒数若没有覆盖率、断流、schema、join 质量和 incident log，几个月后可能无法审计。它不是免费期权，而是需要最低运维投入的数据资产。

### 新增 5：crypto-only 可能变成数据墙锁定，而不是战略聚焦

Claude 已讨论美股/A 股/黄金的优劣，但当前姿态“只做加密”若没有 time-stop 和外部 benchmark，可能从资源聚焦变成路径依赖。加密硬机制数据集中被商业化后，项目可能在同一个付费墙周围反复转圈。

### 新增 6：paper-forward 执行真实性是独立风险

小盘容量 edge 的候选通常最容易在 paper-forward 中虚高：事件窗深度薄、滑点跳变、成交排队、交易所限制、funding/borrow/费率变化都会让纸面判断不可执行。当前姿态强调容量 edge 小盘，但没有要求 paper-forward 同步记录可成交 notional 和滑点假设。

### 新增 7：当前姿态缺 time-stop

“等投研前向战绩”需要明确截止条件：等多久、多少事件、多少失败样本、什么情况下判定 blocked。没有 time-stop，慢路会变成无限路。

## 10. 最终建议

保留当前战略姿态，但按以下顺序补洞：

1. 先写前向投研 ledger 模板和评分规则。
2. 写三账户 promotion/demotion gate。
3. 给强平后台采集加周检指标。
4. 允许一次 data diligence，不允许生产订阅。
5. 给 crypto-only 设置 14 天/30 天 time-stop 和外部 benchmark。

若这些补丁不做，我对当前姿态的评级是 **ACCEPT-with-MAJOR-RISK**：方向能防止乱花钱和乱动核心资本，但证据生产系统还不足以支撑“投研 -> 量化验证 -> 核心资本”的 DEC-091 流水线。

若这些补丁做完，我的评级是 **ACCEPT-with-MODIFY**：它会从“防守性等待”变成“可审计地等待、可证伪地前进”。
