# 投研 Thesis 模板 + Paper-forward 记分标尺（DEC-091 落地物）

**性质：** 投研线（发现/判断/前向纸面层）的登记与评估规范。**不是量化预登记**（不耗独立计数、不碰 Holdout）。
**上位：** DEC-091（量化/投研分线，2026-06-27 三方修订）/ DEC-064（猎机制不猎形态）/ 墓园红线（投研≠看图下单）。
**资本：** 核心资本永不碰；Paper-forward=纸面；Discretionary sandbox 若真钱，单 thesis 最大亏损 ≤ 本金 0.25–0.5%（3万≈75–150元）。

## 准入两道闸（写 thesis 前先过，过不了不立）

**闸0 · 容量 edge 准入（DEC-091 前提一）：** 必须答出"我们凭什么比市场早/好"。小团队无信息/速度优势→唯一诚实 edge=**容量优势**（做大资金看不上的小盘解锁/冷门脱锚/小币强平链/小众结构流）。若大资金也在盯、信息公开、我们不更早不更准 → **这不是投研机会，是带文档的裁量交易，照墓园红线毙，不登记。**

**闸1 · 谁付钱（机制优先）：** 必须指出具体的被迫交易者/信息滞后者/资金约束者/政策摩擦者/结构性流动性来源。答不出"谁付钱、为什么付" → 不登记（= 墓园主体，不管叫投研还是量化）。

## Thesis 登记模板（每个机会事前填，事后补复盘）

```
ID / 日期：
1. 标的 / 事件：
2. 机会类型：解锁 / 强平 / 上币 / 脱锚 / funding极端 / 链上流 / 政策摩擦 / 其他
3. 核心机制（谁被迫交易？谁在付钱？为什么付？）：
4. 容量edge（闸0）：我们凭什么比市场早/好？为什么大资金不做/做不动？
5. 方向判断：看多 / 看空 / 等待
6. 触发条件（什么出现才入）：
7. 入场条件 + 单笔成本闸（闸：预期空间 vs 滑点+手续费+止损距离，毛空间须显著>全成本，否则不做）：
8. 失效条件（什么出现即认错离场）：
9. 观察窗口：24h / 3天 / 7天 / 其他
10. 最大亏损预算（纸面/真钱；真钱≤本金0.25-0.5%）：
11. 事前预测（关键！结算用）：价格方向、波动、成交量、OI、funding、清算/链上指标"会怎样变"——具体到可判定对错
11b. 可交易性字段（2026-07-21 加，外部审计 R2-A-03；方向猜对≠能赚钱，故与方向预测分开）：
   - **唯一可成交入场**：绝对UTC时间戳 + 该时刻可成交价（bid/ask，非中间价）；
   - **唯一退出规则**：止盈/止损/时间退出，机械可判定；
   - **名义仓位口径**：纸面统一 1 单位，供跨条目比 R；
   - **预期费后净 R**：按成本档 0.15%/0.3%/0.5%/1.0% 分别给（毛空间 − 全成本，用哪档取决于标的滑点档）；
12. 复盘结果：命中 / 部分命中 / 失败 ｜ 事前预测准否 ｜ 真实成本是否如预期 ｜ 原因
12b. 可交易性结算（对 11b）：实际费后净 R（各成本档）｜ MAE（最大不利偏移）｜ MFE（最大有利偏移）｜ 失效位是否先于目标触发 ｜ 方向命中但净 R 为负时须显式标注（"对而不赚"）
```

**强制字段（缺一不登记）：** 3（谁付钱）、4（容量edge）、7（成本闸）、8（失效条件）、11（事前预测）。这五项是防"投研退化成事后讲故事"的核心。**11b/12b 为推荐字段**（能取到可成交价即应填）：**方向命中率与可交易 edge 是两级不同的产品**——方向对但小赢大亏/失效位先触发/滑点吞噬照样亏，低于50%命中率若盈亏比正偏也可能正期望；11b/12b 防止"方向命中率"被误当"策略 edge"（与 DEC-096 EDGE_EVIDENCE 口径一致，事件账本 D 组 net_r_at_cost/MAE/MFE 已机器化此测量）。

## Paper-forward 记分标尺（DEC-091 前提二 · 自毁闸）

**目的：** 检验我们是"真能事前判断机制"还是"只是事后解释得漂亮"。

**纪律：**
- **不设"记满 N 个"为目标数**——真机会才记，凑数=制造事后故事。
- 每条 thesis 的字段 11（事前预测）在入场前**冻结时间戳**（写入文件即冻结，不得事后改）。

**评估（积累足够真实 thesis 后，建议 ≥15–20 条真实机会，非硬凑）：**
| 指标 | 说明 |
|---|---|
| 事前方向命中率 | 字段5方向 vs 实际，须显著 > 50%（含盈亏比加权） |
| 预测校准度 | 字段11各项（OI/funding/清算等）事前预测 vs 实际的命中比例 |
| 成本现实度 | 字段7预估全成本 vs 实际，是否系统性低估 |
| 故事 vs 预测 | 命中是否依赖事后重新解释（若大量"部分命中+改口径"=storytelling 信号） |

**PASS（投研线值得继续 / 考虑极小真钱）：** 事前方向命中+校准显著高于随机与事后解释基线。
**FAIL（投研线 KILL，同量化策略一视同仁）：** 事后解释漂亮但事前测不准 → 投研线判 KILL，不留情面，不当"舒适活动"续命。

## ⚠️ grill-me 拷问补强（2026-06-27，修两个短板）
1. **评分考"非显然判断"，非考常识。** "大额解锁→跌"≈同义反复，命中不证明判断力。记分必须考非显然的那部分：**该解锁是否已 price-in（事前能否区分 CARDS 式已跌透 vs NEWT 式未定价）、幅度、时点**。方向对但属常识的，不计入"判断力"得分。

## ⚠️ 二轮结算自查补强（2026-07-15，THESIS #003 TUSDT 结算暴露）
7. **字段11时间判定禁用"期"作单位，一律写绝对UTC时间戳（或小时数）。** 交易所会动态切换资金费结算档（TUSDT 冻结时按 8h 档写"1-2期(8-16h)"，结算时已被切至 1h 档），"N期"在结算时产生口径歧义，只能按不利读法判负。结算档切换（8h→4h→1h）本身是挤压烈度状态变量，可作为触发/退出输入记录。

## ⚠️ 首轮结算自查补强（2026-07-06，THESIS #002 NEWT 结算暴露）
6. **字段11事前预测只准引用基准锁定区的唯一实测数字，禁止"附近/约"等模糊双口径。** THESIS #002 结算时发现字段11写「< $0.053 附近」，而基准锁定区实测数字是 $0.048064——若结算方偷懒按"附近"数字（$0.053）判定，$0.05205 会被误判为命中；按锁定区唯一真实数字判定则是失败。**本条强制：** 冻结预测撰写时必须直接引用同一份"基准锁定"区块里锁死的那个数字，不得另写模糊区间或"约"字措辞；结算时如发现字段11引用数字与基准锁定区不一致，一律以基准锁定区数字为准，不得选对自己有利的读法。
