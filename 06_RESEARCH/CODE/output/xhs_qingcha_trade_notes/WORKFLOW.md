# 小红书交易账号复用工作流

适用场景：
- 输入一个小红书账号链接
- 只看交易相关内容
- 需要后续反复使用
- 希望尽量省 token、少重复说明

## 固定输入

每次只需要给我这三样里的一个或多个：
- 账号主页链接
- 账号昵称
- 你要看的主题范围，例如 `交易相关`、`支撑压力`、`突破`、`仓位管理`

## 固定目标

我默认只做这几件事：
- 找出该账号公开可见的交易相关笔记
- 忽略日常、生活、无关内容
- 生成可复看的笔记目录
- 把内容整理成交易规则骨架
- 如有必要，补成长图或摘要

## 默认过滤规则

我会优先保留这些主题：
- 趋势判断
- 区间判断
- 反转判断
- 真假突破
- 支撑位 / 压力位
- 123 形态
- 黄金分割
- BOLL 中轨
- 开仓逻辑
- 止损 / 止盈
- 仓位 / 加仓 / 追加保证金
- 交易心态 / 执行纪律

我会默认忽略这些内容：
- 纯生活记录
- 情绪化感想但没有交易信息
- 无法落到规则的泛泛而谈
- 与交易无关的收藏、评论闲聊、平台公告

## 标准输出

如果你只说一句“继续整理”，我默认输出这三类东西：
- `manifest.json`：笔记目录
- `README.md`：状态说明和缺口
- `REPORT.md`：交易规则总结

如果你要长期复用，我会尽量补充：
- `WORKFLOW.md`：以后复用的操作说明
- `SUMMARY.md`：这批内容的规则提炼
- `manifest.json` 的补缺状态

## 推荐流程

1. 先确认账号主页可访问
2. 只抓公开可见内容
3. 先按标题筛交易相关笔记
4. 再进入具体笔记看正文和轮播图
5. 生成长图或摘要
6. 抽取可执行规则
7. 把“心法”和“规则”分开写

## 我默认的判断标准

可执行规则：
- 能写成明确条件
- 能做回测
- 能定义入场、止损、止盈、过滤条件

只当参考的内容：
- “静心”“从容”“不强求”这类心态描述
- 没有边界条件的主观经验
- 只适合讲故事、不适合验证的表述

## 省 token 约定

以后你只要发一句下面这种话就够了：

```text
继续整理这个账号，只看交易相关，按固定工作流跑。
```

或者：

```text
整理这个小红书账号的交易相关笔记，沿用上次工作流。
```

这样我会默认沿用：
- 交易相关过滤
- 公开内容优先
- 输出到同一目录
- 保持规则/心法分离
