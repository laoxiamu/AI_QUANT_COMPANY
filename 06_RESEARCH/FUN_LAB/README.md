## 1. 把你扔出来的东西归类

你说的：趋势线、低点连续抬高、连续长影线、缩量止跌、缩量止涨、前低前高止损止盈
小红书补充：123 法则、2B 法则、缠论三类买点、十字星/锤子线/长上影

**按"赌什么"分，只有四类：**

| 类 | 包含 | 赌的是什么 | 互斥关系 |
|---|---|---|---|
| **A 趋势延续** | 低点连续抬高、趋势线、缠论三买 | 涨势没结束，回调后接着涨 | **与 B 互斥** |
| **B 趋势反转** | 123 法则、2B 法则、缠论一买 | 跌势结束了，要转头 | **与 A 互斥** |
| **C 单根 K 线信号** | 长下影、十字星、锤子线 | 一根 K 线的形状能预示下一步 | 可作过滤器 |
| **D 量能确认** | 缩量止跌、缩量止涨 | 量萎缩 = 抛压/买盘耗尽 | **只能当过滤器，不能当主信号** |

**梳理出来的两个判断：**

1. **A 和 B 是对立的。** 一个赌延续、一个赌反转。你不能同时相信两个——**同时用就等于两头下注，那必然被手续费磨死。** 所以要分开测。
2. **C 和 D 不是独立的信号，是过滤器。** "长下影"本身不构成理由（下影线天天有），它只有在"某个位置出现"时才有意义。所以 C/D 应该作为 A/B 的附加条件来测**加了有没有用**。

## 2. 仓位与杠杆（按你的设定，我只做数学翻译）

| 项 | 你的设定 | 实际含义 |
|---|---|---|
| 本金 | 30,000 | |
| 单笔保证金 | 3,000（10%） | |
| 杠杆 | 30× | 名义仓位 = **90,000** |
| 单笔最大亏损 | 900（保证金的30%） | **= 名义的 1% → 你定的其实是 1% 止损** |
| 爆仓线 | — | 约 **3.3%** 反向波动（扣维持保证金后更近） |
| **每笔来回成本** | — | **180 元 = 保证金的 6%** |

**三个必须知道的数：**

- **做 17 笔，手续费就等于一整个保证金**（3000 ÷ 180）
- **1% 止损在 24 小时内被随机打到的概率 ≈ 68%**（12h 56%，4h 32%）——1% 在加密市场是噪声级别
- **1% 止损离 3.3% 爆仓线只有 3 倍距离**，遇到插针/跳空可能来不及成交

**杠杆有一点是被普遍误解的：它不改变需要的胜率**（盈亏和成本同比放大）。它改变的是**爆仓风险**和**资金费**。所以杠杆高低不影响下面的及格线。

## 3. 及格线（本实验室的唯一判据）

**纯随机游走下，1% 止损 + 2% 止盈的胜率 = 33.3%**（因为止盈距离是止损的 2 倍）。

**覆盖 0.2% 成本需要 40.0%。**

> ### 🎯 所以要测的就一件事：
> ### 形态能不能把胜率从 **33.3%** 推到 **40%** 以上？
> ### 绝对 +6.7 个百分点，相对提升 20%。

这个定义的好处：**它把"形态有没有用"变成了一个数字比较**，不需要争论，跑完就知道。

**每个策略都会同时报"随机基准"作对照**——如果策略胜率和随机基准差不多，那形态就是没用，跟赚没赚钱无关。

## 4. 三个策略（分开测，因为赌的东西不同）

### 策略一 · 趋势延续（A 类）

**白话：** 涨势里，低点一个比一个高；回调下来没跌破上一个低点，就买。

| 步骤 | 规则 |
|---|---|
| 趋势 | 4H 图上，最近 3 个摆动低点依次抬高 |
| 回调 | 从近 24h 高点回落 2%–8% |
| **撑住** | 回调最低点 **> 上一个摆动低点**（你要的"前低"） |
| 入场 | 15m 出现阳线且收盘 > 前一根最高价，用其**收盘价** |
| 止损 | **上一个摆动低点下方 0.3%**（你要的"前低止损"） |
| 止盈 | 止损距离 × 2；或**前高**，取先到 |
| 超时 | 24h |

### 策略二 · 2B 反转（B 类，小红书那套）

**白话：** 跌破了前一个低点，但没继续跌，很快又涨回来了——说明跌不动了，买。

| 步骤 | 规则 |
|---|---|
| 前低 | 找最近 48h 内的明显低点 |
| 假跌破 | 价格跌破该低点，但 **4 小时内又收回到该低点上方** |
| 入场 | 收回的那根 1h K 线**收盘价** |
| 止损 | 假跌破的**最低点下方 0.3%** |
| 止盈 | 止损距离 × 2；或**前高** |
| 超时 | 24h |

> **做空版本对称**：突破前高但收不住，反手做空。**同时跑，因为多空对称是你长期要求的。**

### 策略三 · 长下影承接（C 类）

**白话：** 一根 K 线下影线特别长，说明砸下去有人接。

| 步骤 | 规则 |
|---|---|
| 信号 | 1h K 线**下影线 > 实体的 2 倍**，且下影 > 该 K 线全长的 50% |
| 位置 | 必须发生在 24h 内跌幅 > 3% 之后（不是随便一根） |
| 入场 | 该 K 线**收盘价** |
| 止损 | 该 K 线**最低点下方 0.3%** |
| 止盈 | 止损距离 × 2 |
| 超时 | 12h |

## 5. D 类（缩量）怎么用

**不作为独立策略，作为上面三个的开关：**

每个策略跑**两遍**——
- **不加缩量条件**
- **加缩量条件**（信号那根的成交量 < 前 20 根均量）

**对照着看：加了缩量，胜率有没有提高？** 这样才能知道"缩量止跌"这条到底有没有信息量，而不是凭感觉。

## 8. 关于"多个策略一起测"的一个诚实提醒

同时测 3 个策略 × 2 个缩量开关 × 2 个方向 = **12 种组合**。

**测的组合越多，越容易有一个纯靠运气看着不错。** 这叫多重比较问题。

所以看结果时守一条：**只有当某个组合明显好过其他所有组合、而且好得离谱时才值得注意；如果是 12 个里有 1 个刚好过线，那大概率是运气。**

这条我现在写下来，是防止跑完之后我们俩一起盯着最好看的那个说"你看这个行"。
