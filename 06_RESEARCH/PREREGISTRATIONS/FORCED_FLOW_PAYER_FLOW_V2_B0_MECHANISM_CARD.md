## 0. 由来（为什么是 v2，前作死在哪）

三条免费价格软-payer 线连灭于**同一道成本门**：TSMOM 定仓维度穷尽（Baseline）、#X2 跨链 RV（break-even 0.48–0.80%/压力到 4.40%）、#X3 横截面动量（成本门 PASS 但 edge 不在、被动基准 KILL）。DEC-088 三方收敛（Claude 先验 / 零认知子代理 / Codex 红队）把判定**收窄**：

> 死的是「**普通价格形态 + 低维横截面动量**」。**没有死**的是免费**结构资金流数据**（funding / OI / basis / 强平 / taker 失衡）及其与事件的交互——这些项目**从未干净测过**。

v1（P1-RES-036 forced-flow/orderflow）已把 OFI 杀在成本门、清算流转休眠、lead-lag 因无配对数据 KILL。**v2 不是 v1 换皮**：v1 选"最顺眼子机制"先做；v2 把**成本门焊到最前**当立项前置闸，并把猎场从单一 OFI 扩到"结构资金流极端态"family，但仍 WIP=1 收口到单一子机制 + 单一方向。

**本卡机制 = 猎"被迫的资金流在结构极端态留下的、幅度足以盖过全成本的可预测脚印"。价格形态只作触发器/结果变量，绝不作 edge（反 Sweep 铁律）。入场优化留到 B3，且仅当 B2 证出正期望后启用。**

## 1. 机制七问（机制优先，可证伪）

### 问①　谁在持续付钱、为什么付（payer，机制 7 类定位）
候选 payer 全部属 **forced flow / payer flow**（DEC-088 七类机制中最硬的两类），共性＝**非自愿、按规则被迫成交**，不是按价值判断：

| 结构极端态（触发器） | 被迫方（payer） | 付的是什么 |
|---|---|---|
| 强平簇（liquidation cluster） | 被爆仓/ADL 者市价被迫平仓 | 清算冲击成本（在最差价位成交） |
| OI 重置（杠杆骤降） | 追保/去杠杆者被迫减仓 | 去杠杆冲击成本 |
| funding 极端 | 拥挤同向杠杆持仓者，funding 持续放血→被迫止损/被强平 | 资金费 + 平仓冲击（**注意边界，见 §2.4**） |
| taker 失衡（OFI 极端） | 急于成交的激进 taker | 冲击成本 + 价差 |

收钱方＝在"被迫成交扎堆处"预先定位、或提供流动性的一方。Crypto perp 尤强：高杠杆普及 + 永续无到期 + 散户主导 → 强制流频繁且剧烈。

### 问②　钱怎么经路径到我口袋（闭环）
`结构极端态触发（强平簇/OI 重置/funding 极端/OFI 极端）→ 入场（方向＝反转 XOR 延续，看数据前冻结，见 §2.1）→ 持仓（分钟~小时级）→ 平仓 → 收益 − 费 − 滑点`。
⚠️ 成本在极端态时刻**最高**：必须按市价单 + 部分成交 + 级联滑点建模（成本门，§3）。

### 问③　小资金凭什么拿得到（容量优势）
不抢级联首跳（机构速度优势处），吃漫延/反弹/回归段；主流币结构极端态的冲击容量足够小资金；分钟级信号、非共置即可，避开被排除的 HFT 竞速带。**这是猎场过滤器（DEC-087 已松绑为可选），不是验收门。**

### 问④　数据与交易约束允许吗（成本门前置 + 数据功效）
**本卡核心创新——成本门焊在立项最前（见 §3）。** 在选定任何方向前，先证明"该结构极端态后的**合理毛效应上限**"能盖过 70/110/210bp 三档全成本 break-even；过不了即在阶段 A 直接 KILL，不进 B1 实算、不耗计数。数据功效见 §4 阶段 A。

### 问⑤　市场状态/regime 归因
结构极端态本身即 regime 轴（高杠杆拥挤 vs 出清后）。不叠加价格 regime 门控（那是 P1-04/06 价格门控趋势，已证净增量≈0、Sharpe −0.043，叠加=换皮）。

### 问⑥　翻成信号（≥2 可证伪预测，单调性是关键判据）
- **P1（幅度单调）**：结构极端态强度越大，后续窗内同向漂移幅度**单调**越大；若分档无单调 = payer 不机械 = KILL。
- **P2（成本可盖）**：毛漂移幅度上限 > 当档全成本 break-even（70/110/210bp），且在该档下净 E[R]>0。
- **P3（防 beta，第五件）**：触发窗内净收益须超**同状态被动基准**（DEC-069 验收第五件）；否则只是波动 beta。

### 问⑦　方向有误先提异议
若阶段 A 数据显示分档不单调 / 毛效应上限低于成本门 / 仅靠某单一时期撑（如 2021/2022），先提异议判 KILL，**绝不机械续命**（反风险 D）。

## 2. 防换皮裁决（硬约束，四条独立坐实）

### 2.1 反 A-1 门（单一方向预登记，本卡最硬纪律）
A-1 死法＝只赌"清算后回弹"一个方向，且用历史 proxy。v2 **看任何收益前，先冻结单一方向命题**：对选定子机制，**反转 XOR 延续 二选一，写进预登记后冻结，禁两头测择优**。两头测 = A-1/a2 换皮，直接 KILL。冻结依据须在 B1 写明（外部机制依据 + 阶段 A 描述统计的方向先验，但**描述统计不得用 Holdout 段**）。

### 2.2 反 Sweep 白名单门（禁价格形态入组）
入组 / 方向 / 分层只许用**流变量**：清算 notional、signed taker volume、OFI/MLOFI、深度不平衡、spread、OI 变动率、funding 偏离。**任何价格形态（支撑阻力/突破回踩/插针/sweep/结构位/均线/斐波）入组 = Sweep 复活，直接 KILL。** 价格只作结果/成本/基准变量。

### 2.3 反清算-数据-旧伤门（继承 A-1 教训）
免费强平流＝抽样广播/截断（Binance forceOrder 每秒每币 1 条限流，级联系统性低估，非随机噪声）。清算路径**无 ≥2 免费源方向一致 + 缺失机制可界定**，不得进 B2，只能转被动攒数（承接 A-1 路径 B）。

### 2.4 反资金费-carry 门（DEC-084 边界，必须坐实）
DEC-084 禁的是**资金费 carry 型策略**（赚 funding 票息本身）。本卡 funding 极端**只作 forced-flow 触发器/状态输入**（拥挤杠杆被迫出清的信号），**不作 edge 来源、不持有吃票息**。✅ **已放行（DEC-089，Founder D 级 2026-06-22）**：funding 极端放行作 forced-flow 触发器/子机制候选；约束＝**B1 选定 funding 极端为子机制时，须坐实「收益不来自 funding 票息」**，否则回落 DEC-084 禁区判 KILL。B1 子机制候选 = 强平簇 / OI 重置 / funding 极端（带票息约束）/ taker 失衡，四者取一冻结。

## 3. 成本门焊最前（v2 核心，立项前置闸）

**三档全成本 break-even（往返）：**
| 压力档 | 滑点/边 | 费/边 | 往返全成本（乐观费率） | **往返（AGENTS 硬口径 0.1%/边）** |
|---|---|---|---|---|
| 低 | 0.30% | 0.05% | 70 bp | **80 bp** |
| 中 | 0.50% | 0.05% | 110 bp | **120 bp** |
| 高（级联档，强制类强制） | 1.00% | 0.05% | 210 bp | **220 bp** |

（口径＝RESEARCH_PROTOCOL v1.3 增补件二「事件类成本压力档」：基准 0.1% 外报 0.3/0.5/1.0% 三档；清算级联类额外要求最高档 E[R]>0。**⚠️ Codex 阶段A 纠正（2026-06-22，采纳）：AGENTS.md 铁律手续费=0.1%/边，故 B1 验收以 80/120/220bp 为硬门，70/110/210bp 仅作乐观参照。**）

**通过线（缺一不立项）：**
1. 选定子机制的**毛漂移幅度上限**（阶段 A 描述统计给出，非点估计当结论）须 **> 当档 break-even**；强制清算类须在 **210bp 档**仍 E[R]>0。
2. **MDE ≤（毛效应上限 − 全成本）**（v1.4 增补六）：若功效不足以检出"扣成本后的净效应"，禁立项耗计数，改攒数据或换设计。
3. maker→taker 成本敏感带：Founder 提出的限价/maker 挂单可压成本（taker 0.4% → maker ~0.04–0.08%），**但**须同时建模两个 catch——①逆向选择（挂单专挑你错时成交，禁理想成交假设）②挂单价位须由流变量决定，按价格点位挂 = 踩 Sweep 墓园。整条敏感带都过才算 maker 救活。

**过不了成本门 = 阶段 A 直接 KILL，不进 B1。** 这是 v2 对 #X2/#X3/OFI「死在成本门」教训的制度化前移。
