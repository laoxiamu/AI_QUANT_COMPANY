## §1 机制假设（猎机制，自上而下）

**谁在持续付钱·为什么：** 永续 funding 是杠杆多头对空头的周期性支付。加密市场结构性存在**杠杆做多需求**（散户/投机者偏好杠杆多头敞口 + 永续是其主要工具）→ 多头拥挤时 funding 持续为正 → 多头每 8h 付费给空头。这是**行为偏差（杠杆偏好）+ 制度摩擦（永续锚定现货的资金费机制）**双重来源的持续资金流。

**我们凭什么拿到（小资金容量优势）：** 做 delta 中性的"long 现货 + short 永续"组合，成为收 funding 的一方。delta 中性使收益**不依赖价格方向**；小资金在 BTC/ETH 这种深度市场上容量无碍。

**可证伪命题：** 在 BTC/ETH 上构造 delta 中性 long-spot/short-perp 组合并持续收取 funding，**扣全成本后净年化 > 0 且显著跑赢现金零基准**，且最大回撤与负 funding 段可控（核心资本可承受）。

**最可能错处（预登记声明）：** ①funding 可长期转负（杠杆空头拥挤）侵蚀收益；②协议/交易所事件（ETH Merge 类、交易所暴雷、永续脱锚）造成尾部损失；③short 永续腿在价格急涨时保证金不足被强平→delta 暴露。

## §2 构造（冻结，不可修改）

- **品种：** BTCUSDT、ETHUSDT（**SOL 排除**：实证均值 0.4%、2022 -35.6%、funding 不稳）。**权重 BTC 70% / ETH 30%**（实证：BTC 无协议事件风险）。
- **腿：** 每品种 = long 现货 名义 N + short 永续 名义 N（delta≈0）。现货自有（不融资买入），永续用保证金做空。
- **收益来源：** 每 8h 结算时，short 永续在 funding>0 时收取 funding；funding<0 时付出。**主收益=funding，basis 极小不对冲**（C2：p95=+0.11%）。
- **再平衡（冻结）：** 每日 00:00 UTC 检查 delta 漂移，若 |现货名义 − 永续名义|/N > 5% 则再平衡回 delta 中性；否则不动（控制再平衡成本）。
- **杠杆：** 永续腿保证金率冻结 ≤ 2x（仅为保证金效率，**非 alpha 来源**；delta 中性已对冲价格风险）。保证金缓冲：维持保证金 ≥ 交易所最低的 3 倍，防急涨强平。
- **数据：** `*_FUNDING_8H.csv` + `*_MARK_1H.csv`（现货价用对应现货或 mark 近似），UTC，cutoff `< 2024-12-10`（与项目一致，留 Holdout）。

## §4 成本（完整公式，每边口径冻结）

```text
net_funding_pnl = Σ_8h funding_received(short_perp) 
                  - 2*fee_per_side*(开仓+平仓+再平衡换手)
                  - basis_slippage(进出场)

```

## §5 验收（四件套 + 现金零基准 + WF）

**Tier 通过须全部满足（net 口径）：**
- [ ] **E[R] 净 > 0** 且 cluster/块 bootstrap 单侧显著（BTC、ETH 分别 + 组合 70/30）。
- [ ] **四件套**：净 E[R]>0、profit factor、正年比例（≥3/4 历史年）、几何增长 > 0。
- [ ] **现金零基准硬门**（Protocol v1.4 中性类）：组合净收益显著 > 持有现金（0 收益）。
- [ ] **最大回撤可控**：核心资本 sleeve，MDD 门 ≤ 15%（含协议事件情景）。
- [ ] **WF 稳定性**：按时间三段，≥2 段净 E[R]>0（含 2022 熊市段）。
- [ ] **A-1×Carry 触发器**：有触发器版相对无触发器版，净收益不显著恶化、且尾部（事件期 DD）改善。

**FAIL（任一）：** 净 E[R] 不显著 > 0｜现金零基准未跑赢｜MDD>15%｜WF <2 段正｜触发器显著恶化收益却无尾部改善（说明是噪声件）。
**判读纪律：** 不显著点估计只写"未验证"；负 funding 段亏损不得事后剔除。
