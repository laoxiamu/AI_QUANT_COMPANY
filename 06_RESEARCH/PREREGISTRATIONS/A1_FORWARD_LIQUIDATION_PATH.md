# A-1 路径B：前向真实强平数据机制确证通道（设计）

**状态：** DESIGN（非预登记、非执行）｜**依据：** DEC-075 两段式路径B
**作者：** Claude（CTO）｜**日期：** 2026-06-15
**定位：** 解决路径A（历史）的**不可约上限**——历史无真实强平方向数据。路径B用 2026-06-13 起部署的强平采集器**真实清算名义额+方向**做识别，是采集器**首个明确 alpha 用途**。本路径**允许声称强平机制并耗独立 Alpha 计数**（与路径A 关联快筛相反）。

## §1 路径B 凭什么解决路径A 不能解决的问题

| 维度 | 路径A（历史代理） | 路径B（前向真实） |
|---|---|---|
| 强平方向 | 无数据，用 `6h OI↓+负收益` 代理（混入主动减仓/宏观普跌/普通反转） | **采集器原始 forceOrder `o.S` 字段**：`SELL`=多头强平=真实卖压；`BUY`=空头强平=买压。**方向真实可识别** |
| 强平规模 | 无，用 OI 收缩幅度近似 | **真实清算名义额** `o.p * o.q`（或 `o.ap*o.q`），可按品种/时窗聚合 |
| 命题上限 | 仅"条件关联" | **可声称"强平卖压 overshoot 回弹"机制** |
| 计数 | 不耗独立计数 | **耗独立计数**（机制确证实验，受 Protocol §六硬门约束） |

**采集器现状（已核实）：** `aiquant-liq-collector.service` 在腾讯云 SG VM 运行，订阅 `wss://fstream.binance.com/ws/!forceOrder@arr`（全币种强平流），**持久化完整原始 JSON（JSONL）** 到 `/opt/ai_quant_liq_collector/data/LIQUIDATIONS/`。原始消息含 `o.s`(symbol)/`o.S`(side)/`o.p`(price)/`o.q`(qty)/`o.ap`(avg price)/`o.T`(time)——方向与规模字段齐全。

## §2 前向事件定义（设计草案，正式值待预登记冻结）

**机制忠实触发（替代路径A 的价格代理）：**
```text
前向 A-1 事件(t,品种) 候选 ⟺
   (a) 真实多头强平卖压脉冲：滚动短窗(如1h)内 side=SELL 清算名义额 Σ(p*q) 达极端分位(冻结待定)
   且 (b) [可选并验] 同窗 6h OI 收缩（与历史口径对齐，便于路径A/B 可比）
```
关键差异：路径A 用"OI↓+负价"**推断**卖压；路径B 用**直接观测的 SELL 清算名义额**作触发主轴，OI/价格降为辅助/对齐变量。方向不再是代理。

**事件后检验：** 沿用路径A 的 CAR 框架（48h 主 horizon、moving-block 依赖稳健、Holm family），但命题升级为机制层（"真实多头强平卖压脉冲后存在回弹"），且**允许**在通过后声称机制。

## §3 数据累积时间线与就绪门（Readiness Gate）

**核心约束：** 前向数据从 2026-06-13 零起步，n 随时间线性累积。需先估事件率→定就绪门。

**累积监控（建议设为定时任务，低成本）：**
1. 每周从 VM 拉取/聚合 LIQUIDATIONS，按 §2 候选触发口径**统计 BTC/ETH/SOL 月度候选事件数**（仅计数，不看事件后收益，避免提前偷看）。
2. 维护 `A1_FORWARD_EVENT_COUNT.md`：累计候选 n、按品种/月分布、外推达到目标 n 的预计日期。

**就绪门（冻结触发预登记的条件）：** 当池化候选 n ≥ **目标功效门所需**（按 Protocol §六硬门：80% power + 合理效应上限反推 n_min；初估对 1.5% 效应、保守方差，n_min 约百级）→ 触发"路径B 正式预登记起草 + 独立盲审"。**在就绪门达到前不立预登记、不跑事件后收益。**

**预计：** 全币种强平流事件密度远高于单 OI 信号；但限 BTC/ETH/SOL + 极端分位触发后，月度候选可能仍为十位数级。3-6 月达成百级 n 是合理假设，须由 §3.1 实际计数校正。

## §4 治理（与路径A 相反：耗计数、走硬门）

- **耗独立 Alpha 计数**：路径B 是机制确证实验，失败计入 DEC-069 独立计数纪律。
- **Protocol §六硬门生效**：正式预登记须预设 MDE 硬门高于合理效应上限（非路径A 的诊断豁免）。
- **物理盲审**：就绪后须过独立 Risk Reviewer（同路径A 标准，含 Holdout 加密保管、依赖稳健推断等 v4 已闭合的方法学要件，可直接复用 v4 模板）。
- **前向 Holdout**：前向数据按时间或 deterministic index 预留封存，加密保管（同 v4 §12）。
