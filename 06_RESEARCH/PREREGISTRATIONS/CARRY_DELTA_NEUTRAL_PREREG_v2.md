## §1 机制 vs 策略命题（RR1 #1 分离 + 归因表）

- **机制命题（可证伪）：** carry 净收益**主要来自 funding 收取**，而非 basis 波动/价格漂移/再平衡运气。**须冻结归因表**：net_pnl = funding_received + basis_pnl + rebalance_pnl − fees − slippage − financing − event_loss；**声称 carry 机制成立的必要条件 = funding 贡献为正且为净收益主导项**。
- **策略命题：** 上述净收益扣全成本后 > 0 且过 §5 全门。
- **非 alpha 声明（冻结）：** 本策略**不以 funding 极端、价格反转、funding 均值回归为 alpha**；所有正/负 funding 时段一律按冻结持仓规则计入，不择时进出。OI 信号（§3）**只能减仓，不能加仓**。
- **regime/制度依赖声明（冻结）：** edge 是状态依赖非永恒风险溢价。失效监控口径冻结：逐年 + 滚动 12 个月净 funding；funding 公式/交易所制度变更须分段标注；不得结果后挑窗口。

## §2 构造（唯一化，RR1 #2）

- **场所/合约：** Binance；永续 = USDT 本位永续（USDT-M perp）；现货 = Binance 现货同 symbol（BTCUSDT/ETHUSDT 现货）。**现货成交价用 Binance 现货 1H close（非 mark）**；mark 仅用于永续保证金/强平账本，不充当现货成交价或 basis 测量价。若现货历史数据缺失则该段标 N.A.→FAIL，不得用 mark 代替。
- **品种与权重：** 注明为**探索数据所选**（非本数据确认）：BTC、ETH；权重 70/30。SOL 排除同样标注为探索结论。前向 shadow 沿用同一冻结权重，不再在工作集上重选。
- **腿与名义 N：** `N` = 每品种**初始分配名义**（组合总 sleeve 资本 × 品种权重），冻结为常数；long 现货名义 N + short 永续名义 N。
- **再平衡（冻结）：** 每日 00:00 UTC 用当根 1H close 计 `delta_drift = |spot_notional − perp_notional| / N`；>5% → 用**现货腿**成交回中性（perp 腿保持），成交价=次一根 1H open；≤5% 不动。
- **杠杆/保证金（冻结公式）：** 永续初始杠杆 = 1.0（短腿名义 = 保证金，全仓现金保证金）；**保证金缓冲**：维持现金保证金 ≥ 交易所最低维持保证金 × 3；当 mark 上涨致短腿浮亏使现金保证金 < 缓冲线 → 记 `buffer_breach` 并从闲置 sleeve 现金补保证金（补款延迟=次一根 1H）；若补款后仍 < 交易所最低维持保证金 或 无闲置现金 → 记 `liquidation`（短腿强平、delta 暴露、按 mark 平仓损益入账）。
- **basis 路径账本（冻结）：** 每根 1H 记 spot−perp basis 的 mark-to-market；进出场 basis 损益、事件期 basis 扩张全部入账（非仅 p95 滑点）。
- **资本分母（冻结）：** sleeve 资本 = 现货本金 + 永续初始保证金 + 闲置缓冲现金 + 事件备用现金，全部计入收益率分母。

## §3 A-1×Carry 风控触发器（完整状态机，RR1 #3）

- **变量（冻结）：** `oi_6h_pctl(t)` = 名义 OI（`sumOpenInterestValue`）的 6h 变化 `d6h = oi(t)/oi(t-6h)−1` 相对**严格过去** `[t-365d, t)` 扩张窗（最少 180 日历日、≥720 有效样本）的 midrank 滚动分位（不含当前值）。数据源=Binance USDT-M perp metrics 5M→1H 取末值不前填。**检验的是"6h 骤降"（d6h 下尾），非低 OI 水平。**
- **状态机（冻结）：** `oi_6h_pctl ≤ 0.01` 触发 → 该品种目标仓位降至 50%（用现货腿，次一根 1H open 成交）+ 启动 24h refractory；refractory 内再触发**不延长**（首触发计时）；24h 到期若当根不再触发 → 次一根 1H 一次性恢复 100%；仍触发 → 续 24h。BTC/ETH 独立各自状态机。减/恢复换手均计 §4 成本。
- **非劣检验（冻结，替代 v1 模糊表述）：** 配对 = 同一历史路径"有触发器"vs"无触发器"两套净值；检验 `H0: ΔnetER ≤ −δ`（净收益恶化超过非劣界 δ），`δ=年化0.5%`，单侧 alpha=0.05，同步 UTC 双资产块 bootstrap、块长=1 周等效、seed=20260614。
- **唯一尾部指标硬门（冻结）：** 触发器须使**事件期短腿 `liquidation` 次数**相对无触发器版**严格减少**（≥1 次或归零）。
- **基础 carry 必须先独立过 §5 全部硬门**；触发器版仅判"是否保留触发器"，**禁止有/无触发器版择优包装 edge**。

## §4 成本（逐腿逐成交账本，RR1 #4）

```text
每次成交单独计：cost = notional_filled * (fee_per_side + slippage_per_side)
fee_per_side = 0.10%（现货腿、永续腿各自每次成交都算）
slippage_per_side = 0.10% 基准；事件压力档 0.30% / 0.50% / 1.00%（§6 事件窗内用压力档分别报告）
换手来源：开仓、平仓、每日再平衡、触发器减仓/恢复、强平 —— 全部逐笔计 fee+slippage
funding_received = Σ_8h (perp_short_notional_at_settle * funding_rate)   # 实际结算名义，交易所 funding 上下限按其公式
financing = 0（全仓自有现金保证金，无借贷；冻结为确定值，不留事后选择）
其它入账：basis MTM 路径损益、强平损益、ADL/破产损失（事件期）、脱锚退出、保证金资产折价
```

## §5 验收（Protocol 四件套闭合 + 唯一二元，RR1 #5）

**观测单位（冻结）：** 8h funding interval 的组合净收益序列（含成本归属到 interval）。
**主推断：** 同步 UTC 双资产（BTC/ETH 向量）**多变量块 bootstrap**，块长=1 周等效 interval 数（21），复制=2000，seed=20260614，单侧 alpha=0.05，报告点估计 + 95% CI。

**FEASIBILITY-LOCK PASS（历史，全满足；仅"历史可行性复核通过"，不耗计数、不上线）：**
- [ ] 净 E[R]（年化）> 0 且块 bootstrap 单侧显著。
- [ ] **赢亏比 ≥ 1.5**（赢均/亏均，按 8h interval 净收益）。
- [ ] 正年比例 ≥ 多数（Protocol 口径；注明 4-5 独立年下符号检验功效弱，见 §8）。
- [ ] **年化 log growth > 0**（唯一公式 `mean(ln(1+r_interval))*interval/年`）。
- [ ] **现金零基准硬门**：组合净收益显著 > 0（现金=0 收益）。
- [ ] **分档爆仓概率**（同步块 bootstrap、2000 条 1 年路径、seed）：标准档 `P(年DD≥35%)≤20%` 且保守档 `P(年DD≥20%)≤10%`；**路径内逐 1H 检查短永续腿维持保证金/强平**，非仅组合收盘 MDD。
- [ ] **组合 MDD ≤ 15%**（含 §6 事件情景）。
- [ ] **WF**：按时间等分 3 段（边界=工作集 interval 数三等分，余数给前段；切点 purge 跨界持仓；段内不重估参数），≥2 段净 E[R]>0。
- [ ] 触发器非劣（§3）+ 尾部硬门（§3）。

**FAIL（任一）：** 上述任一不满足；或任一必要项 `N.A. ⇒ FAIL`（数据缺失/事件无法建模/强平概率无法计算均不得跳过）。
**判读纪律：** 不显著点估计写"未验证"；负 funding 段/事件期亏损不得剔除。

## §8 功效门（先过，RR1 #5/#6）

- 序列 `n_eff = n/(1+2Σρ_k)`，ACF 截断 lag=预登记 30 个 8h（=10 天），估计样本=工作集全段；该数仅描述样本内序列精度。
- **独立制度周期 ≈ 4-5 年**。单侧 alpha=0.05、power=80% 的年度 MDE（来自 RR1 表）：n_eff=4 → 1.65σ；n_eff=5 → 1.36σ。
- **合理净 edge 上限（事前经济约束，非工作集反推）：** carry 风险溢价学术与跨市场先验 ≈ 年化 5-12%；保守取上限 12%、年度 SD 假设 10% → MDE@n_eff=5 ≈ 13.6%。**即历史段功效本就偏弱**——这正是 §0 把历史降为"可行性复核、不耗计数"、把确认交给前向 shadow（可累积更多独立月）的根本理由。
- **若坚持以历史段耗独立计数确认 → 禁止**（MDE≈合理上限，功效不足，Protocol v1.4）。

## §9 失败后禁止行为
FEASIBILITY-LOCK FAILED 后禁止：改 funding 阈值/权重/再平衡/触发器/事件窗后在同工作集重测；剔除负 funding 段或事件；把不显著写成"弱 edge"；把历史可行性复核冒称独立确认或据以上线核心资本。重立项须新预登记 + 重新盲审 + 用前向/独立数据。
