## 动机

新上市 USDT-M 永续合约在上市后 7-30 天可能存在系统性价格发现错位。做市商在初期库存和对冲工具不足时会要求更高风险补偿，初始保证金与杠杆约束会放大被动平仓和追涨杀跌压力，媒体关注度冲击会把短期流动性需求集中到少数时间窗。若对冲/套利资金尚未充分进入，付钱的一方可能是承担错位价格的散户流动性提供方和被动追单者；他们用更差成交价交换即时流动性和叙事暴露。该机制只在上市早期有经济含义，窗口过长会被套利进入和信息扩散稀释。

## 检验

事件研究版，无 WF。替代方案：pre-Holdout 工作集内做池化事件统计、年份分层、固定分箱单调性检验、置换检验，并用块 bootstrap 估算分档爆仓/尾部风险；Holdout `1/5` 物理封存，任何情况下不得读取。

验收四件套（事件研究版）：

1. `E[R] > 0`：事件窗口净 log return 均值扣除手续费、基础滑点、真实 funding 后为正；压力滑点 `0.3% / 0.5% / 1.0%` 单独列示，不得用“部分有效”措辞。
2. 赢亏比 `>= 1.5`：episode 级平均盈利 / 平均亏损，按冻结窗口和成本后计算。
3. 分档爆仓概率：按固定风险档用块 bootstrap（seed 预登记）估算，不读取 Holdout；若样本 `<300`，使用池化 + 单调性，不做 60/20/20 三分。
4. 年化 log 增长 `> 0` 且分年正期望占多数：按事件发生顺序构造等权事件组合，不允许用全样本调仓或后验过滤。

第五件：

- 对照基准：同期等权买入所有同批次新上市合约并持有至窗口结束。
- 判定：策略净值或事件均值必须显著高于该基准；若正式变量仅为“窗口”且策略等同于基准，则第五件无效，必须退回重写机制或基准。
