## 2. 公司终态

### 2.1 推荐终态

公司以 `1 Founder + Claude + Codex + 确定性程序` 的微型结构持续完成：

```text
市场机制机会
  -> 可审计证据
  -> 冻结策略规格
  -> 接入统一交易平台
  -> 受控执行与结算
  -> 风险处置与恢复
  -> 绩效归因与资本配置
  -> 决策、结果和事故沉淀为知识
```

终态必须能持续做到：

1. 只让有经济机制、经预登记和前向证据支持的 edge 接触资本。
2. 诚实淘汰失败方向，不用点估计、改参数或 Holdout 为失败叙事翻案。
3. 核心资本与围栏资本物理/逻辑分层，杠杆只表达已验证 edge。
4. 多策略复用一套最小交易平台，不按策略重复建设订单、状态、风控、监控和账务。
5. Track A 确定性执行与 Track B AI 分析隔离；AI 不进入实时下单权限链。
6. 订单、持仓、风险和账务以 PostgreSQL/持久文件为权威，禁止内存字典成为状态源。
7. 任何交易、异常、资本调整和研究结论均可复现、追溯和审计。
8. Founder 日常只处理 D 级事项和异常决策，目标干预时间不超过约 30 分钟/日。

### 2.2 明确不做

- 当前不对外募资、不做资管产品、不卖信号或 SaaS。
- Phase 2 前不建设重型 UI、移动 App、RL、自进化交易或多智能体实时执行。
- 未有通过前向证据的策略前，不为“未来可能用”而完整建设生产系统。
- 不以文档数量、模块数量或组织图完整度作为公司建设完成标准。

### 5.1 矩阵结论

1. 当前最关键串联路径是：`carry 证据 -> 策略规格 -> 最小平台 -> 实时风控 -> 监控/响应 -> 账务/对账 -> paper shadow`。
2. 平台、风控、监控、账务任何一项缺失，都不能用“小额先上线”绕过。
3. 当前最明显的“无人负责”不是公司方向，而是 Phase 2 日常运行接口：谁接告警、如何接管、如何复账、何时恢复。
4. 当前最危险的“重复建”是让每个策略在循环 E 中自建订单、状态、风险、监控和账务。
5. 治理和研究流程已足够成熟，近期新增建设资源应偏向运行能力，不继续扩张治理文档。

## 6. 阶段划分

> 以下阶段终态、出口条件和关键路径均为推荐版，待 Founder D 级确认。阶段跨越由可运行证据决定，不由文档完成率决定。

### Phase 0：原则与证据基础

- **阶段终态：** 公司知道为什么存在、如何判断 edge、谁能决策、失败如何归档、状态在哪里读取。
- **当前状态：已达到。**
- **出口条件：**
  - 目标函数、两层资本、机制优先和项目止损原则已确认。
  - 研究协议覆盖成本、WF、Holdout、功效、事件研究和叙事纪律。
  - 决策、墓园、报告、任务通知和状态恢复链可用。
  - 至少一个完整失败研究能被复现并诚实归档。
- **跨域关键路径：** 战略资本 -> 治理审计 -> Alpha研究 -> 项目交付。
- **不得遗留到后续的缺口：** 双任务台账、Holdout 权限模糊、历史文件直接继承。

### Phase 1：Edge 与最小可运行平台

- **阶段终态：** 至少一个机制完成锁定历史复核并取得前向 shadow 资格；公司具备用冻结规格做确定性 paper 运行的最小平台。
- **当前状态：进行中。**
- **出口条件：**
  - 至少一个活体方向通过历史可行性门，且结论未被独立 Reviewer 否决。
  - 已形成策略 SPEC、成本/仓位模型和 ATD。
  - paper 平台具备持久状态、数据合同、模拟执行、基础风险、结构化日志和账务对账。
  - 交易所/DB/runtime 三方对账差异为零；重启恢复和急停演练通过。
  - 前向 shadow 协议冻结，尚不启用真实资金。
- **跨域关键路径：** Alpha研究 -> 策略产品化 -> 平台数据 -> 实时风控 -> 运营监控 -> 账务归因。
- **当前最近出口：** carry v4 `FEASIBILITY-LOCK` 二元判决。

### Phase 2：受控 paper 与小额实盘

- **阶段终态：** 用冻结策略和最小资金验证真实成交、成本、风险、恢复、账务和运营闭环。
- **当前状态：未进入。**
- **入口硬门：** Founder D 级确认 Phase 1→2；至少一个策略取得前向/纸面运行资格；平台五项运行能力全部通过。
- **出口条件：**
  - 前向 shadow 按预登记观察窗完成，不 optional stopping。
  - Founder 批准后，至少一个策略完成小额真金观察窗。
  - 无未解释订单、持仓、现金、funding 或 NAV 差异。
  - 风险阻断、急停、重启恢复和异常接管演练通过。
  - 真实成本与 PnL 可按策略、机制和事件归因。
  - 资本调整均由证据化 D 级决策驱动。
- **跨域关键路径：** 信号到结算 -> 异常到恢复 -> 绩效到配置。

### Phase 3：稳态复利与有限扩展

- **阶段终态：** 七条价值流稳定运行；新增策略只接入平台；资本在证据边界内复利和有限扩展。
- **当前状态：未来阶段。**
- **入口硬门：** Founder D 级确认 Phase 2→3 的资本上限和公司范围。
- **出口/稳态条件：**
  - 多个观察期持续满足正期望、几何增长、风险和对账门。
  - 新策略不复制底座，平台变更有兼容和回滚路径。
  - 事故率、恢复时间、状态漂移和账务差异保持在冻结阈值内。
  - 资本扩张不突破 Founder 确认范围；外部募资/对客业务若出现，必须另立公司级决策和总图版本。
- **跨域关键路径：** 绩效到配置 -> 决策到交付 -> 结果到知识 -> 新一轮机会到证据。
