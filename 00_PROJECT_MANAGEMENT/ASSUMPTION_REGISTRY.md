# 假设登记表

**用途：** 捕获项目中"最没被质疑的假设"——那些被默认为真、从未被检验、一旦错误就会让大量执行白费的前提。防止"埋头执行不质疑框架"的根因复发。  
**使用规则：**  
1. 每个新研究方向/系统决策开工前，**先问：这里隐含的假设是什么？** 把它写进本表。  
2. 标注验证状态（未验证/部分验证/已验证/已证伪）和验证方法。  
3. 假设被证伪后不删除——改状态为"已证伪"并写后果，防止换皮复活。  
4. 若假设未被验证但执行已开始，标注"带假设执行"和触发条件（何时会强制验证）。

**等级分类：**  
- **A 级（致命）：** 假设错误会直接导致资金损失或研究完全无效  
- **B 级（重大）：** 假设错误会让大量工作浪费但不直接伤本金  
- **C 级（中等）：** 假设错误会需要调整但损失可控
